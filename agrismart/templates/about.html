How it works

Farmers often pick crops by habit. AgriSmart compares a field's soil and weather with what each crop usually grows best in.

1. Data in SQLite

pandas reads {{ n }} rows ({{ crops }} crops) from the {{ source }} and writes them to the samples table. Crop facts live in crops, and your saved fields in predictions.

2. Model in scikit-learn

A Random Forest of 150 decision trees learns the pattern from 80% of the rows. On the other 20% it is right {{ accuracy }}% of the time.

3. Advice with pandas

For the winning crop, each input is compared with the crop's average and spread. More than one standard deviation away becomes a plain-language tip.

4. Website in Flask

The sliders send JSON to /api/predict. The page redraws with the answer, and Chart.js draws the dashboard from /api/stats.

Dataset

Source: {{ source }}. Each row is one field: N, P, K, temperature, humidity, pH, rainfall and the best crop (label). NumPy is used for the top-3 ranking and the radar chart scaling.
